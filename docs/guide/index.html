The shangOS guide

A complete manual for your TV remote. shangOS is organized around three pages — Home, Apps, and Settings — navigating via standard remote directional pads with fluid, predictable motion.

The Home screen

Home opens with a calm greeting (personalized via Settings), today’s date, and your selected wallpaper. The top edge houses the clock (optional) and a minimal page indicator for jumping between Home, Apps, and Settings.

Directly below sits your curated primary application row. The focused card features an ambient light glow, moving between cards applies a slight parallax tilt to the wallpaper, and pressing OK launches it, its window growing out of the card. The light behind the row takes the colour of the app you are on (Settings → Room lighting turns it off), and the line under the app’s name says what you were watching (“Continue: … · 18 min left”, from the Continue watching list you allow in Privacy) or when you last opened it, and stays true while you sit there. Subtle ambient lighting glides across the wallpaper when idle, pausing immediately upon any key press or after 10 minutes of inactivity (30 minutes on the Quality tier).

The Apps page

The second page displays all installed Leanback and standard applications without exception. Holding OK on any tile lifts it: move it with the d-pad and press OK again to put it down (Back puts it down where it is). Order changes persist across both the Apps page and the Home row. If you put the tile down without moving it, its menu opens:

  • Open and Move to first position.
  • Hide from Home — Keeps an app accessible in the full Apps list while removing it from the calm Home row.
  • App info — The system page of the app.
  • Uninstall — Asks Android to remove an app you installed; Android asks you to confirm. Not offered for the TV’s own apps.

Home Widgets

Widgets populate below the application row on Home, cycled using remote vertical directions (▲ / ▼). Settings → Home widgets includes a live interactive editor allowing you to reorder, enable, or disable widgets with immediate preview.

Widget Display Information Required Permissions
Up Next Android TV Continue Watching items (from Netflix, YouTube, Plex, Jellyfin) and recent applications. Pressing OK deep-links into the specific program. Read TV Listings (Optional for third-party Continue Watching)
Now Playing Active media playback session (Spotify, YouTube Music, Plex) showing cover art, playback scrubbing, and remote control keys. Notification Access (Android requirement to read active MediaSession tokens; no notifications are read)
Control Quick status tiles for Wi-Fi connection, picture mode, sound, and Bluetooth remotes. Selecting a tile opens the corresponding system menu. None
Inputs Physical HDMI input selector and antenna tuner. HDMI-CEC connected hardware displays custom assigned device names. None
Weather Local forecasts derived from the TV’s timezone capital city. Toggles between hourly and 7-day outlooks. Cached locally on disk. Opt-in (Disabled by default; queries Open-Meteo with coarse city coordinates)

Settings Overview

Settings opens over a soft translucent scrim so wallpaper changes reflect in real-time. A live card tracks your focused category:

Category Functionality
Wallpaper Visual gallery picker featuring all eight looks with live full-bleed previews.
Your name Custom greeting string, stored strictly on-device in application private storage.
Clock Toggle the Home screen corner clock visibility.
Performance Toggle rendering profiles: Auto, Light, Balanced, and Quality.
Home widgets Live drag-and-drop widget toggler and ordering manager.
Privacy Inspect network switches, permission states, and APK signature verification.
Setup guide Relaunch the initial first-run onboarding sequence at any time.
About Binary version, authorship, commit hashes, and SPDX open source licenses.

Wallpapers & Rendering

Your own photo: from a computer on the same network, run ./shangos.sh wallpaper ~/photo.jpg. The picture goes straight into shangOS’s private storage over adb: no media permission, no Photos or cloud account, no network. It appears in Settings → Wallpaper as “Your photo” and the screen saver shows it dimmed. ./shangos.sh wallpaper --remove deletes it.

Eight distinct environments are included. Six were procedurally synthesized for this launcher: Aurora, Ember, Tide, Orchid, Glacier (high-contrast for sunny rooms), and Daybreak (solar-synchronized daylight transition). Two are high-resolution CC0 photographs: Milky Way and Calm Sea from Poly Haven.

Rendering is handled directly on a dedicated render thread without compositing bloat. Motion is suspended during remote interactions and entirely disabled on the Light performance tier. Texture buffers immediately unbind and free memory when backgrounded.

Performance Tiers

On first boot, shangOS inspects available RAM, CPU architecture, and core counts to set an optimal hardware profile:

Tier Behavior & Budget
Auto Hardware-inferred profile (Default). Displays rationale in Settings.
Light Static wallpapers, zero background render passes. Tuned for budget 1.0–1.5 GB streaming sticks.
Balanced Subtle wallpaper motion and parallax within a strict frame budget.
Quality Full dynamic lighting shaders and 30-minute idle sleep thresholds.

Privacy Controls

Consolidated into a single settings pane displaying live socket and permission states:

  • Weather Toggle — Disabled out-of-the-box. Displays disclosure of city coordinates prior to first query.
  • Remote Posters — Off / Wi-Fi & Ethernet only / Always.
  • Runtime Offline Mode — One switch that instantly cuts all outbound application HTTP sockets.
  • Build Signature — Displays the SHA-256 fingerprint of the installed APK to verify against release attestations.

First-Run Wizard

Upon initial launch, an interactive 5-step setup covers performance tier selection, privacy preferences, optional permissions, and primary launcher configuration (complete with a pairing QR code linking to our setup guide). All steps can be skipped with Back.

Updates & Uninstallation

Subsequent releases are signed with identical private keys and install directly over existing versions without wiping app ordering or wallpaper preferences. To restore factory TV firmware defaults, see our Undo Guide.

For Developers

Written in native Java with zero third-party dependencies, single-process execution, and a single main Activity. Layouts are computed using native design-grid units (1/960 of display width). Complete technical documentation is maintained in the repository:

  • Architecture Guide ↗ — Package structure, module responsibilities, and layer boundaries.
  • Release Pipeline ↗ — Cryptographic signing keys, automated reproducibility checks, and CI security attestations.
  • Build & Test Matrix ↗ — Running ./build.sh release | offline | debug and executing headless emulator harness scripts via ./test/run.sh.
