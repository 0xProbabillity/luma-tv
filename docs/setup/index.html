Installation & Deployment

Put shangOS on your TV

Android TV and Google TV do not expose a standard launcher picker in their consumer menus. Setting shangOS as your default home screen is done once from your computer via adb (Android's standard developer tool) over local Wi-Fi. It takes about five minutes, requires no rooting, and is 100% reversible.

Prerequisites

An Android TV or Google TV running Android 12 or newer, a computer connected to the same home Wi-Fi network (macOS, Linux, or Windows via WSL/PowerShell), and your TV remote.

System Impact

Zero core TV firmware is overwritten. HDMI switching, Chromecast, picture calibration, and Bluetooth remotes operate uninterrupted. The factory launcher is simply silenced and can be re-enabled at any time.

1. Enable Wireless Debugging on the TV

  1. Unlock Developer Options

    Navigate to Settings → System → About on your TV. Scroll down to Android TV OS build (or Build) and press OK 7 times until you see the prompt: “You are now a developer!”

  2. Enable Network Debugging

    Go back to the System menu and open Developer options. Toggle USB debugging to On (some TVs label this Network debugging or Wireless debugging).

  3. Note the TV’s Local IP Address

    Open Settings → Network & Internet and select your active Wi-Fi or Ethernet connection. Note the local IP address assigned to your TV (for example: 192.168.1.50).

Menu locations on common devices

Hardware PlatformMenu Navigation Path
Chromecast with Google TV, onn., TCL, Hisense Settings → System → About → Build (7x), then System → Developer options
Sony BRAVIA (Google TV) Settings → System → About → Build (7x), then System → Developer options
Android TV Boxes (Nvidia Shield, Mi Box) Settings → Device Preferences → About → Build (7x), then Device Preferences → Developer options

Note for newer Google TV builds: If your device enforces pairing authentication, select Wireless debugging → Pair with pairing code under Developer options, execute adb pair <TV-IP>:<port> in your terminal with the 6-digit code shown, then connect to the standard network port.

2. The Quick Way: Automated Script

Ensure you have Android platform-tools (ADB) installed on your machine, then run:

$ curl -fsSL https://shangos.madusha.dev/setup.sh | bash

The automated script scans your local network for ADB-enabled televisions, prompts for an IP address if automatic discovery fails, downloads the latest cryptographically signed release from GitHub, checks its SHA-256 hash, and sets shangOS as the primary launcher.

Watch Your TV Screen

During the first connection attempt, your television will display an “Allow USB debugging?” modal. Select “Always allow from this computer” and press OK with your remote.

To inspect the script prior to execution:

$ curl -fsSL -o setup.sh https://shangos.madusha.dev/setup.sh && less setup.sh
$ bash setup.sh # Add --yes --tv 192.168.1.50:5555 for unattended setup

Interactive Repository Wizard

For advanced workflows — building from source, managing multiple TV environments, selective permission tuning, or clean uninstallation — use the interactive repository wizard:

  1. Clone the Project Repository 
    $ git clone https://github.com/madushas/shangos-launcher.git && cd shangos-launcher
  2. Launch the Terminal Interface 
    $ ./shangos.sh wizard

    Navigate with arrow keys (or j/k), select with Enter, and choose edition variants (Standard vs Offline) dynamically.

Manual ADB Walkthrough

If you prefer running manual commands step-by-step:

# 1. Connect to your television
          $ adb connect 192.168.1.50:5555

          # 2. Install the official signed release
          $ adb install -r shangos-*.apk

          # 3. Designate shangOS as default home handler
          $ adb shell cmd package set-home-activity --user 0 dev.madusha.shangos/.MainActivity

Press the Home button on your remote. If the factory Google TV launcher intercepts the Home button, disable it temporarily:

# Silence aggressive factory home package
          $ adb shell pm disable-user --user 0 com.google.android.tvlauncher
          $ adb shell cmd package set-home-activity --user 0 dev.madusha.shangos/.MainActivity

Optional: Grant Leanback recommendations and media control permissions:

# Up Next continue watching listings
          $ adb shell pm grant dev.madusha.shangos android.permission.READ_TV_LISTINGS

          # Now Playing active playback controls
          $ adb shell cmd notification allow_listener dev.madusha.shangos/dev.madusha.shangos.MediaListener

Restoring Factory Default (Undo)

shangOS leaves zero permanent modifications. You can revert completely at any time:

Via Setup Script:

$ bash setup.sh --uninstall

Manually via Terminal: Re-enable your original stock launcher package:

# Re-enable standard factory launcher
          $ adb shell pm enable com.google.android.tvlauncher
          # (Or on newer Google TV firmware: com.google.android.apps.tv.launcherx)

          # Remove shangOS cleanly
          $ adb uninstall dev.madusha.shangos
Order of Operations

Always re-enable your stock launcher before uninstalling shangOS, ensuring your television always has a valid home activity registered.

Cryptographic Checksum Verification

Validate release integrity and security attestations using standard toolchains:

$ sha256sum -c SHA256SUMS
          $ apksigner verify --print-certs shangos-v0.3.0-release.apk

The resulting certificate SHA-256 fingerprint matches the release notes on GitHub and the in-app signature in Settings → Privacy → This build.

Troubleshooting Reference Matrix

Reported IssueRemediation Procedure
failed to connect Ensure both TV and host computer share the identical subnet/Wi-Fi band. Confirm Wireless debugging is active in Developer options. On newer firmware, complete adb pair with the pairing code modal.
unauthorized Inspect your television display. An Android authorization prompt has appeared: select “Always allow from this computer” and confirm with OK.
Home opens old launcher Some Google TV builds aggressively reclaim Home button intents. Execute the adb shell pm disable-user command in the manual section above to silence the factory package.
INSTALL_FAILED_UPDATE_INCOMPATIBLE Occurs when migrating between Release and Offline editions (or custom builds) signed with different certificates. Execute adb uninstall dev.madusha.shangos first, then install the new APK.
Discovery timeout mDNS broadcast packets may be filtered by your home router. Pass your TV's explicit local IP address to the script: bash setup.sh --tv 192.168.1.50:5555.
