Set shangOS as your home screen

Most TVs do not offer a "choose your launcher" setting, so this is done once from a computer with adb (Android's standard debugging tool). It takes about five minutes and is fully reversible.

You will need: an Android TV or Google TV on Android 12 or newer, a computer on the same network, and the TV's remote.

1. Allow debugging on the TV

  1. Open Settings → System → About. Press OK on Android TV OS build (or Build) seven times until it says you are a developer.
  2. Settings → System → Developer options. Turn on USB debugging (some TVs call the network option Network debugging or Wireless debugging).
  3. Find the TV's address: Settings → Network → your network shows an IP address such as 192.168.1.50.

2. The easy way: the setup wizard

  1. Install Android platform-tools on your computer (it contains adb).
  2. Download the source from GitHub (or the latest release) and open a terminal in that folder. The script is for Linux, macOS, and Windows with WSL.
  3. Run ./shangos.sh wizard. It lists the TVs it can see, lets you type an address (for example 192.168.1.50:5555), asks which edition you want, downloads the signed release and checks its checksum, installs it, and makes it the home screen. Accept the prompt that appears on the TV the first time.

Every command that changes the TV is printed before it runs, and the wizard has a clean-up menu.

3. The manual way

adb connect 192.168.1.50:5555
adb install -r shangos-v0.3.0-release.apk
adb shell cmd package set-home-activity --user 0 dev.madusha.shangos/.MainActivity

Press the Home button. If your TV still opens its own launcher (Google TV often does), that launcher has to be switched off; this is reversible:

adb shell pm disable-user --user 0 com.google.android.tvlauncher
adb shell cmd package set-home-activity --user 0 dev.madusha.shangos/.MainActivity

Optional: let shangOS read what you were watching and what is playing:

adb shell pm grant dev.madusha.shangos android.permission.READ_TV_LISTINGS
adb shell cmd notification allow_listener dev.madusha.shangos/dev.madusha.shangos.MediaListener

Undo it

With the wizard: choose Give Home back to the TV's own launcher. By hand:

adb shell pm enable com.google.android.tvlauncher

Press Home. If it still opens shangOS, the wizard's Give Home back restores exactly the launcher your TV used before (it remembers which); by hand, uninstall shangOS with adb uninstall dev.madusha.shangos and the TV falls back to its own. The launcher's package name differs between TVs: com.google.android.tvlauncher is the common one, com.google.android.apps.tv.launcherx is Google TV's newer one.

Before uninstalling shangOS give Home back first, so the TV is never left without a home screen. The wizard does this for you.

Check what you downloaded

sha256sum -c SHA256SUMS
apksigner verify --print-certs shangos-v0.3.0-release.apk

The certificate fingerprint printed must match the one on the release page and in the app (Settings → Privacy → This build). Releases also carry a GitHub build-provenance attestation (gh attestation verify).

Troubleshooting

What you seeWhat to try
failed to connectThe TV and computer must be on the same network, and debugging must be on. Some TVs show the address only after you turn debugging on.
unauthorizedLook at the TV: accept the "Allow USB debugging?" prompt (tick "always allow").
Home still opens the old launcherUse the second command block in step 3, or let the wizard do it.
INSTALL_FAILED_UPDATE_INCOMPATIBLEA build signed with another key is installed: uninstall it first (adb uninstall dev.madusha.shangos; its settings are cleared).
