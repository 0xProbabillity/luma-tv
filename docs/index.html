Core Principles

Tuned for human peace of mind

Modern television operating systems are built as advertising real estate. shangOS reclaims your living room as a high-fidelity display.

Zero Sockets

Air-gapped and kernel isolated

No telemetry, no background analytics, no cloud pings, and no crash collectors. Our dedicated Offline Edition is compiled without the android.permission.INTERNET declaration entirely — meaning Linux kernel socket creation is blocked at the operating system level.

Optimized for modest sticks

Tuned and benchmarked on a 1.4 GB, 32-bit streaming stick. Built in native Java without React Native, Flutter, or WebView bloat. Animations stay locked at 60 Hz on inexpensive hardware.

Up Next & Now Playing

Direct integration with Android’s system-level MediaSession and Leanback recommendations. Seamlessly resume SmartTube, Jellyfin, Plex, or Netflix without ad rows interfering.

No rooting. The factory launcher is simply silenced via official Android ADB debugging flags. Run one command to revert your television back to its out-of-the-box factory state in seconds.

Common Questions

Frequently asked questions

Why is ADB debugging needed to install shangOS?

Unlike Android phones, modern Android TV and Google TV systems do not expose a “Default Home App” picker in their consumer settings menu. Setting shangOS as your primary launcher is completed once via ADB (Android's standard developer interface) over your local home Wi-Fi network. Once configured, pressing the remote’s Home button opens shangOS instantaneously.

Will this break my TV, casting, or HDMI inputs?

No. shangOS exclusively replaces the visual home screen layer. All fundamental TV hardware and platform capabilities — including Google Cast (Chromecast receiver), HDMI CEC input switching, picture mode calibration, and Bluetooth voice remotes — operate completely outside the launcher and continue functioning uninterrupted.

How do application updates work?

To update, install the newer APK over your existing install (via the setup script or standard ADB). Because every official release is signed with our persistent cryptographic release key, Android preserves your wallpaper configurations, custom app drawer sorting, and hidden app settings.

Can I revert back to the stock factory launcher at any time?

Yes, completely. Running bash setup.sh --uninstall or selecting “Restore Factory Launcher” in the setup wizard immediately re-enables your manufacturer launcher. You can also re-enable it manually via standard ADB commands at any time. Zero traces remain.

What is the difference between Release and Offline builds?

The standard Release APK includes network permission strictly to query coarse Open-Meteo forecasts (if turned on) and to download Up Next artwork cards. The Offline edition is compiled without android.permission.INTERNET declared in its manifest, guaranteeing that the Android operating system kernel refuses any outbound connection attempts.
