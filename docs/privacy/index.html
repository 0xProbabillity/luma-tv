Privacy

shangOS has no accounts, no analytics, no crash reporting and no update check. It never sends anything about you to its author. The app shows the same information on the TV: Settings → Privacy.

The network

FeatureWhenWhat is sent, and to whom
WeatherOnly if you turn it on (off by default)A request to api.open-meteo.com with the rounded coordinates of your time zone's main city (about 1 km). Open-Meteo sees this TV's internet address and nothing else.
Remote postersWi-Fi and Ethernet only, unless you change itThe cover pictures that apps publish for Up Next are fetched from the address the app gave, over HTTPS only, and never from addresses inside your home network.

Offline mode (Settings → Privacy) switches both off. The offline edition of the app is built without the Internet permission, so Android itself blocks every connection.

Stored on the TV

Your settings, the last list of apps (so Home appears instantly) and a small picture cache. Nothing is backed up to any cloud (allowBackup is off). Uninstalling removes it all.

Verify it

The source is open: network code lives in one file (Net.java), settings in another (Prefs.java), and the project's checks fail if that changes.
