Security & Privacy

Privacy Architecture

shangOS has zero accounts, analytics trackers, crash monitors, or background telemetry pings. It collects no identifiers and contains no server backends. The application mirrors this page identically in Settings → Privacy.

Network Usage

Only two features within the Standard Release APK can initiate outbound TCP sockets, both strictly under user control:

Feature Trigger Conditions Payload & Remote Endpoint
Weather Widget Strictly opt-in (disabled by default) Sends an HTTPS GET query to api.open-meteo.com containing coarse coordinates (~1 km radius): of the main city of your TV's time zone, or of the city you pinned in Settings → Weather location. Open-Meteo receives only the TV's external IP address. Searching for a city there sends the text you type to geocoding-api.open-meteo.com, and only while you search.
Remote Poster Artwork Wi-Fi and Ethernet only by default Cover posters published by installed media apps for the Continue Watching row are retrieved from the HTTPS URL declared by the app. Queries never target local RFC-1918 private LAN addresses.

Runtime Offline Mode: Toggling this switch in Settings → Privacy immediately cuts all network threads. Furthermore, our dedicated Offline Edition APK is compiled without the android.permission.INTERNET declaration, ensuring the Linux kernel blocks all outbound socket creation at the OS level.

Declared Permissions

Android Permission Architectural Justification Requirement Level
READ_TV_LISTINGS Enables Up Next Continue Watching cards shared by streaming apps. Read-only. Optional
PACKAGE_USAGE_STATS Ranks recent applications by actual foreground launch timestamps. Optional
BIND_NOTIFICATION_LISTENER Accesses active media playback controls (Now Playing). The listener contains zero notification-parsing logic; it binds strictly to the OS MediaSessionManager. Optional
REQUEST_DELETE_PACKAGES Lets the launcher ask Android to show its own uninstall confirmation when you choose Uninstall on an app’s menu. Nothing is removed unless you confirm there. On request
ACCESS_NETWORK_STATE Checks for unmetered Ethernet or Wi-Fi before attempting poster queries. System
INTERNET Queries Open-Meteo weather and loads Up Next posters. Completely stripped from the Offline Edition. Opt-in Only

Local On-Device Storage

All user configurations, custom app rankings, and cached asset previews reside exclusively on local device flash in /data/data/dev.madusha.shangos/. Cloud synchronization (android:allowBackup) is hard-coded to false in the manifest. Uninstallation permanently wipes every stored byte.

Auditing & Reproducibility

All network logic is isolated into a single source file (Net.java), and application preferences are kept in (Prefs.java). CI static analysis checks enforce this boundary at every pull request. Check the cryptographic SHA-256 fingerprint on your television in Settings → Privacy → This build and compare it with GitHub release attestations.
