Licenses and credits

shangOS contains zero third-party Java libraries or SDKs. This page documents all standalone components, datasets, and creative commons assets bundled or queried by the launcher — mirroring Settings → About → Licenses in the app.

Component Author / Origin License (SPDX) Purpose
shangOS madushas & contributors MIT The primary launcher application and system daemon.
Luma TV 0xProbability MIT Upstream architecture shangOS was originally forked from.
Poly Haven Poly Haven & artists CC0-1.0 The Milky Way and Calm Sea photographic wallpapers.
Open-Meteo Open-Meteo.com CC-BY-4.0 Opt-in coarse weather forecast API queries.
IANA Time Zone DB IANA Public Domain Reference coordinates for time zone-inferred city mapping.
Roboto Google Apache-2.0 Letterform glyphs rendered in the TV banner visual.

Full license declarations are bundled directly in the application binary and maintained in the repository root within LICENSE and NOTICE.md.

The generative dynamic themes — Aurora, Ember, Tide, Orchid, Glacier, and Daybreak — were procedurally synthesized specifically for this project and are published under the MIT license.
